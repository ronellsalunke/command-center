# Usage

## Log in

Enter your password at `/login`.
You stay logged in for 30 days on that browser.
Log out from the header button.

## Projects list

- Search filters by name (`/` focuses search).
- `+` opens a blank project page with the cursor in the name field.
- Click anywhere on a card to open it.
- Trash deletes the project and all its fields after confirmation.

## Project details

- The title row has a back button, the project name, and a pen to rename.
- Renaming uses Save/Cancel. `Esc` cancels.
- Click a value to open it (links) or copy it (plain text).
- Pen edits a field, copy icon copies it, trash deletes it after confirmation.
- Drag the grip to reorder. Reorder is disabled while filtering.
- The dashed row at the bottom adds a field. Keys need a non-empty value.

## Keyboard

- `/` focuses search or filter.
- `j` / `k` moves selection.
- `e` edits the selected field.
- `c` copies the selected value.
- `Alt` + `ArrowUp` / `ArrowDown` reorders the selected field.
