KV UI examples

Keyboard: j/k move, e edit, c copy, / search. Click a value to edit. It looks like text until hover or focus.

A. Inline rows — recommended

Key fixed left. Value blends in. Copy and Open appear on hover. Best for repo, package name, docs mix.

B. Link cards

Best when most values are URLs. Icon initial, domain line, copy plus open.

C. Dense table

Most Notion-like. Muted key column, inline value, row hover actions.
